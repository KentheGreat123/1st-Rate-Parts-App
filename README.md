# 1st Rate HQ — web app

Upload everything in this folder to the root of the GitHub repo, then turn on GitHub Pages:
Settings → Pages → Source: Deploy from a branch → main / (root) → Save.

App address: https://kenthegreat123.github.io/1st-Rate-Parts-App/

Note: GitHub Pages on a private repo needs a paid GitHub plan (Pro/Team). On a free plan, make the repo public or use Netlify Drop.
